## JavaScript

### 개념 정의
- 객체(Object): 여러 개의 데이터를 `key-value` 형태로 묶어서 관리하는 자료형.
- 프로퍼티(Property): 객체를 구성하는 `key-value` 한 쌍
- 메서드(Method): 객체의 프로퍼티 값으로 사용되는 함수

### 왜 쓰는가?
- 서로 관련된 여러 데이터를 하나의 단위로 묶어서 관리하기 위해 사용한다.

---
### 오늘 알게 된 점
- JavaScript는 C언어와 비슷한 문법이라 비교적 익숙했다. 다만 `===` 이 연산자는 처음 배웠는데, 값뿐만 아니라 타입까지 모두 일치하는지 비교한다, 반대로 `==` 은 암묵적 타입 변환 후 값을 비교한다는 차이도 새롭게 알게 되었다.
- 객체를 선언할 때 `const`를 주로 사용하는 이유가 궁금했다. `const`로 선언하더라도 객체 내부의 프로퍼티 값은 변경할 수 있고, 객체 자체를 다른 객체로 재할당하는 것만 제한된다는 점을 알게 되었다. 따라서 객체를 다른 객체로 다시 할당할 필요가 없다면 `const`를 사용하는 것이 적절하다.
