## 화살표 함수
- 화살표 함수(Arrow Function): 함수를 더 간결하게 작성할 수 있는 문법이다.
    ```javascript
    const add = (a, b) => {
        return a + b;
    };
    // 한 줄로 반환하는 경우, 중괄호와 return을 생략할 수 있다
    const add = (a, b) => a + b;
    // 매개변수가 하나일 경우 소괄호를 생략할 수 있다
    const double = num => num * 2;
    ```
    - 화살표 함수는 자신만의 this를 가지지 않고, 자신이 선언된 바깥 스코프의 this를 사용한다.
    - 따라서 객체의 메서드처럼 호출한 객체를 this로 사용해야 하는 경우에는 일반 함수를 사용하는 것이 적절하다.
    - 화살표 함수는 생성자 함수로 사용할 수 없으며 new와 함께 호출할 수 없다

## 배열 (Array)
: 여러 개의 데이터를 하나의 변수에 순서대로 묶어서 관리할 수 있는 자료구조이다.

- 배열 메서드
    - `push`: 배열의 끝에 요소를 추가하고 새 길이를 반환
    - `pop`: 배열의 끝에 요소를 제거하고 제거된 요소를 반환
    - `unshift`: 배열의 앞에 요소를 추가하고 새 길이를 반환
    - `shift`: 배열의 앞에 요소를 제거하고 제거된 요소를 반환
    - `indexOf(x)`: x 값이 처음으로 나오는 인덱스 반환. 없으면 -1
    - `includes(x)`: x 값이 있으면 true, 없으면 false

- 심화 메서드
    - `forEach()`: 배열 요소 하나씩 전달받으며 콜백함수 실행. 단, 반환값은 항상 `undefined`. 주로 각 요소에 대해 동작을 수행할 때 사용
    - `map()`: 배열 요소 하나씩 전달받으며 콜백함수의 반환값으로 새 배열을 만든다
    - `filter()`: 콜백함수의 반환 결과가 true인 요소만으로 새 배열을 반환.
    - `find()`: 처음으로 조건을 통과한 요소 하나를 반환.
    - `some()`: 조건에 맞는 요소가 하나라도 있으면 true, 없다면 false.
    - `every()`: 모든 요소가 조건에 맞으면 true, 아니면 false.
    - `sort()`: 배열을 정렬한다. default는 문자열 오름차순 정렬이므로 정렬 기준을 명시해야 한다. 원본 배열 자체를 변경한다.
        ```javascript
        numbers.sort((a, b) => a - b); // 숫자 오름차순 정렬
        ```
        - 음수 → a를 b보다 앞에 배치
        - 양수 → b를 a보다 앞에 배치
        - 0 → 두 요소의 상대적인 순서를 유지
    - `reduce()`: 콜백의 반환값이 다음 반복의 누적값이 된다. 
        ```javascript
        array.reduce(<콜백 함수>, <초기값>);

        const numbers = [2, 4, 3, 1];
        const sum = numbers.reduce((acc, num) => acc + num, 0);
        console.log(sum); // 10
        ```
        1. acc = 0 으로 초기화한다.
        2. numbers 배열 요소를 순차적으로 num에 할당한다. num = 2
        3. 콜백함수의 코드를 시행한다. 0 + 2 = 2 반환된 값을 acc에 다시 할당한다.
        4. 배열의 마지막 요소까지 2~3번을 반복한다.

## 배운 점
- JavaScript에서는 배열의 인덱스 범위를 벗어난 위치에 접근해도 IndexError와 같은 에러가 발생하지 않고 undefined가 반환된다는 점이 Python과 달랐다.
- sort()는 기본적으로 숫자 크기가 아니라 문자열 기준으로 정렬하기 때문에 숫자를 정렬할 때는 비교 함수를 직접 전달해야 한다는 점을 알게 되었다.
