<!-- React 개념, 동작 방식, intro, component-jsx, props -->

- React = virtual DOM 이 있기 때문에, 이전 DOM 과 비교하여 변경사항만 업데이트한다. 그래서 속도가 빠르다/효율적이다.
- Component란
- 클래스형 컴포넌트
- 함수형 컴포넌트
- Hooks: 클래스형 컴포넌트에서만 사용할 수 있는 기능이 있는데, 
- JSX 문법: 자바스크립트 확장 문법. 자바스크립트의 실제 문법은 아니기 때문에, 번역이 필요하다. => 이 기능을 하는 애 = babel

- JSX 특징
    1. {} 안에 자바스크립트 표현식을 넣을 수 있다.
    2. HTML 속성과 약간 다른 규칙을 따른다.
    3. 인라인 스타일은 '객체' 형태로 전달해야 한다.
    4. 모든 태그는 반드시 닫혀야 한다.

- virtual dom
    - root에 clock 컴포넌트 그려줘 실행 -> 해당 부분만 변경시키고 있다. element 보면 깜박거림

- props: 부모 컴포넌트가 자식 컴포넌트에게 데이터를 전달하는 '통로'
    - 읽기 전용 데이터. 자식은 props를 수정할 수 없음

App 컴포넌트에 태그를 사용하여 실행 코드 반환, 태그 내 속성에 값을 전달 = 인수전달
props = {name='홍길동' favoriteNumber={5}}

- Hook: 함수형 컴포넌트가 React 기능을 사용할 수 있게 연결해주는 함수
