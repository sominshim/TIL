## CSS
- `:hover`: 마우스를 요소 위에 올렸을 때 특정 스타일을 적용하는 가상 클래스
- `transition`: CSS 속성값이 변경될 때 자연스럽게 이어지도록 전환 효과를 적용하는 속성

## JavaScript
### 변수 선언 키워드
- `var`: 과거에 주로 사용하던 변수 선언 키워드. 재선언과 스코프 등의 문제로 현재는 `const`, `let` 사용을 권장한다.
- `const`: 값을 재할당하지 않을 변수를 선언할 때 사용하는 키워드
- `let`: 값이 변경될 수 있는 변수를 선언할 때 사용하는 키워드

### 암묵적 타입 변환
- JavaScript가 연산과정에서 자동으로 변환
```javascript
"10" + 5 // "105"
```

### 명시적 타입 변환
- 개발자가 함수를 사용해 직접 데이터 타입을 변환하는 것
```javascript
Number("10") // 10
String(10)   // "10"
Boolean(1)   // true
```


### 오늘 알게 된 점
- JavaScript에서 Falsy로 판단되는 대표적인 값은 0, "", false, null, undefined, NaN이 있다.
- CSS 선택자를 지정하는 방법이 조금 헷갈렸는데, :hover, transition 등을 직접 실습하면서 선택자와 스타일 적용 방식에 대한 개념을 다시 정리할 수 있었다.
- JavaScript의 기본 문법을 학습하면서 const와 let의 차이와 사용 기준을 이해했다. 또한 암묵적 타입 변환과 명시적 타입 변환이 어떤 상황에서 이루어지는지 알게 되었다.
