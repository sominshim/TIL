## HTML

### 개념 정의
Hyper Text Markup Language. 웹 페이지의 내용과 구조를 정의하는 마크업 언어이다.

### 왜 쓰는가?
제목, 본문, 이미지, 링크, 입력 폼 등 웹 페이지에 필요한 요소를 구조적으로 표현하기 위해 사용한다.

#### Semantic Tag 
화면에 보여지는 것보다 내용의 의미에 맞는 태그를 사용하는 것이 좋다.
예를 들어, `<strong>`과 `<b>`는 모두 기본적으로 굵게 표시하지만 의미는 다르다. 
- `<strong>`: 중요한 내용임을 의미
- `<b>`: 의미상의 중요도 없이 시각적으로만 굵게 표시

따라서 태그의 의미를 고려하지 않고 오용하거나 남용하면 문서 구조를 이해하기 어려워지고, 접근성이나 검색 엔진 최적화(SEO) 측면에서도 불리할 수 있다.

또한 웹 페이지의 영역도 의미에 따라 구분하는 것이 좋다.
- `<header>`: 페이지 또는 영역의 머리말
- `<main>`: 페이지의 주요 콘텐츠
- `<footer>`: 페이지 또는 영역의 하단 정보

이처럼 의미에 맞는 태그를 사용하는 것을 Semantic HTML이라고 한다.


### 몰랐던 내용/헷갈렸던 내용
#### 테이블 관련 태그
- `table > thead > tr > th` : 
    - `tr`: Table Row. 테이블의 한 행을 묶는 태그
    - `th`: Table Header. 테이블 제목이나 컬럼명을 나타내는 태그. 가운데 정렬 + 굵은 글씨
- `table > tbody > tr > td` :
    - `td`: Table Data. 테이블의 실제 데이터를 나타내는 태그

#### 태그 속성
- `id`: HTML 문서 안에서 특정 요소를 식별하기 위한 고유한 값
- `name`: Form 데이터를 서버에 전달할 때 사용하는 변수명
- `value`: 해당 name과 함께 서버로 전달되는 실제 데이터 값

## CSS

### 개념 정의
Cascading Style Sheets. HTML로 작성한 웹 페이지에 디자인과 레이아웃을 적용하는 스타일 시트 언어이다.

### 왜 쓰는가?
글자의 크기와 색상, 배경색, 간격, 정렬, 배치 등 웹 페이지의 표현 방식을 지정하기 위해 사용된다.

### 주요 선택자
- `태그명`: 특정 HTML 태그 선택
- `.클래스명`: 해당 클래스를 가진 요소 선택
- `#아이디`: 해당 id를 가진 요소 선택
- 우선순위: 태그 < 클래스 < 아이디

---
### 오늘 알게 된 점
- HTML에 왜 이렇게 다양한 태그가 필요한지 궁금했는데, 각 태그가 문서의 의미와 구조를 표현하기 위한 것이라는 점을 알게 되었다. 이를 통해 검색 엔진이나 브라우저가 문서의 핵심 내용과 각 영역의 역할을 더 잘 이해할 수 있고, SEO와 접근성에도 도움이 된다는 것을 배웠다.
- form 관련 속성 중 id와 name의 역할이 항상 헷갈렸는데, 데이터를 서버로 전달할 때는 name=value 형태로 전달된다는 점을 기억해야겠다. name은 전달되는 변수명, value는 실제 값이며, id는 HTML 문서 안에서 특정 요소를 식별하기 위한 고유한 값이라는 것도 정리할 수 있었다.
